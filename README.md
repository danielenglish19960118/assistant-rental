## 🛠️ Quick Start Guide

### Option 1: Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/assistant-rental.git
   cd assistant-rental
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the platform:**
   ```bash
   npm start
   ```
   *Visit `http://localhost:3000` in your browser to launch the rental portal.*

---

### Option 2: Run with Docker

1. **Build the Docker Image:**
   ```bash
   docker build -t assistant-rental .
   ```

2. **Run Container:**
   ```bash
   docker run -p 3000:3000 assistant-rental
   ```
